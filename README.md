# 🌐 RO-NET Telegram Bot

Telegram-бот для інтернет-провайдера **RO-NET**, розроблений на базі **Aiogram 3** з повним функціоналом управління послугами.

---

## ✨ Функціонал

- 👤 **Особистий кабінет** користувача з усіма даними
- 💰 **Перевірка балансу** та históія платежів
- 📋 **Перегляд тарифних планів** з детальним описом
- 🔄 **Зміна тарифного плану** з миттєвим оновленням
- 💳 **Оплата через Monobank** з безпечною обробкою платежів
- ⚡ **Швидка оплата** без додаткових кроків
- 🚀 **Перевірка швидкості інтернету** (speed test)
- 📍 **Перевірка покриття** за адресою
- ❓ **FAQ система** із частими питаннями
- 🛠️ **Технічна підтримка** з можливістю створення заявок
- 📊 **FSM сценарії** для складних взаємодій
- 🗄️ **SQLite база даних** для зберігання даних
- 🌐 **Webhook режим** для розгортання на Render

## 🌐 Деплой на Render

### Крок 1: Створення сервісу

1. Відкрий [Render Dashboard](https://dashboard.render.com)
2. Натисни `New +` → `Web Service`
3. Підключи GitHub репозиторій

### Крок 2: Налаштування Build

| Параметр | Значення |
|----------|----------|
| **Build Command** | `pip install -r requirements.txt` |
| **Start Command** | `python main.py` |

### Крок 3: Environment Variables

Додай наступні змінні в панелі Render:

| Ключ | Значення |
|------|----------|
| `BOT_TOKEN` | Твій Telegram Bot Token |
| `BASE_WEBHOOK_URL` | `https://your-app-name.onrender.com` |

### Webhook URL

Бот автоматично встановлює webhook:

```
https://.onrender.com/webhook
```

## 🐛 Розв'язання проблем

### ❌ Бот не запускається

Перевір:
- ✅ Чи встановлені всі залежності: `pip install -r requirements.txt`
- ✅ Чи заповнено `.env` файл коректно
- ✅ Версія Python: `python --version` (повинна бути 3.11+)

### ❌ Webhook не працює

- ✅ Перевір `BASE_WEBHOOK_URL` в `.env`
- ✅ Переконайся, що Render сервіс активний
- ✅ Перевір логи: `tail -f render.log`

### ❌ Проблеми з базою даних

- ✅ Видали старий `database/db.sqlite` файл
- ✅ Запусти бота заново, БД створится автоматично
